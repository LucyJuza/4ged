# ihm2_2024_3_rol-mic-juz-and

## Description

L'idée de l'application est de créer une plateforme web avec une base de données de jeux et des profils de joueur·euse·s ainsi qu'une librairie de jeu. L'utilisateur·ice a la possibilité d'ajouter des jeux via l'API de BoardsGameGeek ou d'ajouter son jeu custom si cellui-ci ne fait pas partie de celle-ci. Chaque compte permettrait de suivre les joueur·euse·s, incluant des statistiques comme le temps de jeu moyen et le score moyen. L'application fournirait également des informations détaillées sur les performances de celleux-ci. L'objectif est d'insérer, d'analyser et de présenter des données de jeu de manière accessible et visuelle.
